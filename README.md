# FUTURE_ML_03
Resume / Candidate Screening System

## Objective
This project builds an ML system to automatically screen and classify resumes based on job category.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization

## Dataset
Resume Dataset

## Features
- Resume text cleaning & processing
- Candidate category prediction
- Model accuracy evaluation
- Sample resume prediction

## Output
The model predicts the most likely job category for a given resume.
